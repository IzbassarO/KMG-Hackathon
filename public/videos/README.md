# public/videos — собственные видео (self-hosted)

Сюда кладутся видеофайлы, которые проигрываются **прямо в UI проекта** (без YouTube) —
например, выступление директора/Председателя или ролики курсов.

## Как добавить видео

1. Положите файл сюда, например `chairman.mp4` (форматы: `.mp4` / `.webm` / `.ogg`).
   - `.mp4` (H.264 + AAC) — самый совместимый вариант для браузеров.
2. В `lib/media.ts` укажите **путь** вместо ссылки на YouTube:

   ```ts
   export const VIDEO_LINKS = {
     chairmanWelcome: "/videos/chairman.mp4",        // ← локальный файл из public/
     viceChairmanWelcome: "/videos/vice-chairman.mp4",
     strategy2030: "https://youtu.be/...",           // ← или по-прежнему YouTube
     hseIntro: "/videos/hse-intro.mp4"
   };
   ```

Файлы из `public/` доступны по корню сайта: `public/videos/chairman.mp4` → `/videos/chairman.mp4`.
Плеер курса сам выберет `<video>` для локального файла и `<iframe>` для ссылки YouTube.

## Важно

- **Не загружайте чужие видео с YouTube** — это нарушает авторские права и правила YouTube.
  Хостить можно только собственные материалы КМГ (на которые у вас есть права).
- Большие файлы раздувают git-репозиторий. Для тяжёлых видео лучше:
  - добавить их в `.gitignore` и раздавать отдельно/через CDN, **или**
  - хранить на корпоративном видеохостинге и вставлять ссылку.
