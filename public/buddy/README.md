# public/buddy — ассеты персонажа Digital Buddy

Компоненты персонажа рисуют **встроенный SVG** по умолчанию, но автоматически
подменяют его на файлы из этой папки, если они есть. Достаточно положить ассеты
организатора хакатона (ТЗ §4.2 — PNG с прозрачным фоном) — код менять не нужно.

| Файл                      | Где используется                                   | Рекомендация            |
|---------------------------|----------------------------------------------------|-------------------------|
| `character.png`           | полная фигура (шапка «Мой день», окно гида)        | PNG, прозрачный фон, ≥400×520 |
| `avatar.png`              | круглый аватар (лаунчер, чат, шапка окна)          | квадрат, ≥160×160       |

Видео-обращение (если будет) подключается отдельно — ссылку положить в
`CHAIRMAN_VIDEO_URL` (`lib/buddy.ts`).

Подмена реализована через `onError` в компонентах:
`components/buddy/buddy-character.tsx` и `components/buddy/buddy-avatar.tsx`.
Если файла нет — тихо используется SVG-фолбэк, ошибок в консоли нет (кроме одного
ожидаемого 404 на отсутствующий ассет в dev-режиме).
