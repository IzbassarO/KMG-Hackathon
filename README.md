# KMG Onboarding Portal — Digital Buddy

Цифровая платформа онбординга и адаптации новых сотрудников АО НК «КазМунайГаз»:
персональный маршрут адаптации по дням, гид-персонаж **Digital Buddy**, AI-ассистент
на корпоративной базе знаний и сквозная аналитика для HR — в одном окне.

---

## Возможности

- **Digital Buddy** — гид-персонаж: игровое обучение по интерфейсу, ежедневные карточки
  корпоративной культуры, напоминания и чат-помощник.
- **AI-ассистент** — отвечает на вопросы по ВНД и регламентам КМГ (Groq LLM) со ссылками на
  источники, строго в рамках рабочих и корпоративных тем; доступен на всех экранах.
- **Маршрут адаптации по дням** — план на каждый день от Дня 1 до Закрепления, четыре этапа
  (Знакомство → Вовлечение → Адаптация → Закрепление); задачи, курсы, опросы и встречи
  открываются по мере адаптации.
- **Обучение** — курсы в формате Coursera: материалы, видео и тесты; прогресс и завершение
  сохраняются и видны HR.
- **Flowchart-тикеты** — этапы онбординга как наглядные процессы с зависимостями шагов.
- **Badge Center** — генерация корпоративного бейджа по документам и фото 3×4, печать и выдача.
- **Менторство 30/60/90** — контрольные точки по датам, чат и запрос встреч 1:1 с HR.
- **HR-аналитика** — прогресс сотрудников, метрики адаптации (вход в систему, пунктуальность,
  риски), пульс-фидбэк и отчёты по адаптации на 14 / 30 / 90 день.
- **Три языка (RU / KZ / EN) и тёмная тема** — переключатель в правом верхнем углу.

## Технологии

Next.js 15 (App Router) · React 19 · TypeScript · TailwindCSS · @xyflow/react · Groq LLM.

---

## Запуск

```bash
# 1) зависимости
npm install

# 2) ключ AI-ассистента
cp .env.example .env.local      # впишите GROQ_API_KEY — https://console.groq.com/keys

# 3) старт
npm run dev                     # http://localhost:3000
```

Продакшн-сборка и проверка типов:

```bash
npm run build
npm run typecheck
```

- Ключ Groq читается только на сервере из `.env.local` и в репозиторий не попадает.
- На лендинге выберите роль и демо-аккаунт; язык и тему — переключатель в шапке.

## Демо за минуту

1. Войдите как **сотрудник** (Асылбек Гизатов) — запустится обучение Digital Buddy, затем план Дня 1.
2. На «Мой день» переключайте **день адаптации** (1 → 14 → 30) — план, карточки культуры и курсы
   открываются по мере роста дня. Откройте курс, спросите AI-ассистента.
3. Войдите как **HR** (Нурлан Жумабаев) — входящие запросы 1:1, аналитика, обучение, Badge Center.
