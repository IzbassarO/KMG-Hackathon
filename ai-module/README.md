# ai-module — RAG / векторная база (Digital Buddy AI)

📦 **Это место для ИИ-модуля, который разрабатывает коллега.**

ИИ-часть (RAG-поиск по ВНД + векторная база) ведётся отдельным разработчиком.
Готовый модуль (код RAG + документация по сборке и запуску) будет добавлен
в эту папку и проинтегрирован с порталом.

По ТЗ (раздел 7) ИИ-модуль — это **отдельный Docker-контейнер** со стеком:

| Слой           | Технология                                  |
|----------------|---------------------------------------------|
| Векторная база | ChromaDB                                    |
| Эмбеддинги     | sentence-transformers (multilingual RU/KK)  |
| Парсинг ВНД    | docling / pypdf                             |
| RAG            | LangChain                                   |
| БД профилей    | PostgreSQL 15+                              |
| Deploy         | Docker + docker-compose                     |

## Точка интеграции с фронтендом

Портал общается с ИИ-модулем по REST. Когда модуль будет готов:

1. Поднять контейнер из этой папки (`docker compose up`).
2. Указать адрес сервиса фронтенду через переменную окружения
   `NEXT_PUBLIC_RAG_API_URL` (например `http://localhost:8000`).
3. Точка подмены на стороне портала — `lib/rag.ts` (сейчас TF-IDF заглушка).

> Внутреннюю структуру модуля, эндпоинты и формат ответов определяет
> документация разработчика ИИ-части. Этот README — только указатель на папку.

## Готовые данные для модуля

В папке уже лежат 23 карточки Culture Fit (ТЗ §5.2.2), подготовленные с фронт-стороны:

- **`data/culture_fit_nudges.md`** — карточки по секциям (день/тема/источник ВНД/текст).
  Удобно загружать в **векторную базу (RAG)**: одна секция = один чанк.
- **`db/nudge_cards.sql`** — схема + INSERT'ы таблицы `nudge_cards` для **PostgreSQL**
  (ТЗ §9 MVP: «Все 23 карточки загружены в банк → PostgreSQL»). Применение:
  `psql "$DATABASE_URL" -f db/nudge_cards.sql`.

Тексты карточек идентичны тем, что показывает портал
(`lib/program.ts` → `CULTURE_CARDS`) — единый источник истины.
